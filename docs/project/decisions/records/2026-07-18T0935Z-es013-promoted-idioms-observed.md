# ES-013 promoted; connector idioms held as observed, not yet canonical

## Question

ES-013 (connectors as net structure — the liaison net) sat at Candidate
with three calls waiting on the Navigator (raised as DEC-002 on the desk):
promotion, adoption of the four connector idioms as catalog patterns, and
the Driver's mission-wording interpretation (changes land on the PR branch
rather than merging to the simulated repo's main).

## Decision

**DEC-002 option 2** (first desk sitting, 2026-07-18):

1. **ES-013 is promoted out of Candidate.** The exploration question is
   answered with running evidence (two live LLM runs, 45 dedicated tests,
   recorded histories).
2. **The four connector idioms — cursor-token cadence,
   inhibit-as-breath-holding, acceptance-consumes-the-fuel, desk-as-sensor
   — are held as "observed, not yet canonical."** Upgrade condition, so
   the follow-up is mechanical: a **second connector independently reusing
   an idiom makes it canonical** for the pattern catalog. The nearest
   witness is ES-018 (the Instagram channel); its ratification (DEC-015)
   should check which idioms it reused and canonize exactly those.
3. **The PR-branch reading is confirmed.** Good changes land on the PR
   branch and earn review; auto-merge to main mid-review is not the model
   the connector should express.

The quiescence-only-sensing design question is deliberately untouched —
it is DEC-003 and independent of this promotion.

## Why

One net is proof, not vocabulary: naming patterns after a single witness
is how catalogs accumulate speculative entries, and a second witness was
already three rulings away in the same sitting chain. The PR-branch
reading is the more defensible model of "good" — review-before-merge —
and merging into main mid-review would drain the PR the simulated team is
still evaluating.
