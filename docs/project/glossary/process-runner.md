# Process Runner

The DST wall-clock containment axis: one complete scenario
invocation executed in a child OS process, so a hung or runaway run
cannot stall the harness.

- Do not use for: a Petrus [Process](process.md) — the runnable
  composition of a net with its bindings and stores.
