# Workload

The application-owned adapter over one opaque runtime generation, naming the
doors, commands, faults, observations, and bounds a World may use — the same
role FoundationDB and TigerBeetle call a workload.

- Do not use for: Agenticus runtime profiles or History Store/Dispatch
  product profiles — those name production capability boundaries.
- Avoid: scenario profile (former name; the `ScenarioProfile` class is
  pending rename).
