# Fault

One occurrence-addressed failure a DST schedule injects at a
workload-owned durability boundary: commit refusal, acknowledgement loss,
crash, and kin.

- Do not use for: an Activity failure — that is a production value
  returned by an activity, not a harness injection.
- Related: [Durability boundary](durability-boundary.md),
  [Activity failure](activity-failure.md)
