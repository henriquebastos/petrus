# Net document

The one strict portable `petrus-net-document` envelope: exactly one
canonical Net-definition v3 document, optionally a Layout and one
forkable Timeline. Which optional facts are present determines what a
consumer can show and safely change; authority, not file shape,
decides read-only versus editable.
