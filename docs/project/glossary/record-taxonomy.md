# Record taxonomy

Reader vocabulary for History's record kinds: initiation records mint
a firing occurrence's id, boundary records open and close it, movement
records are tokens crossing the marking, activity records freeze
external work's request and outcome, and effect records are
delivery-registration opens/closes. Records name the world's event in
past tense, never the ledger's own act.
