# Petrus

The public project and umbrella identity over Impetus, Motus, and Arx,
and the name of the one Python distribution, source root `src/petrus`,
and top-level namespace. A running Petrus system composes Impetus's
event History and Petri-net responsibilities with Motus's Activity
responsibilities.

Related: [Impetus](impetus.md), [Motus](motus.md), [Arx](arx.md),
