# CV20.DS4 — Generated authoring and worked examples

## Intent

Let a human or agent generate, review, diagnose, and repair a runnable Petrus
flow through the same selected authoring and canonical contracts taught by
worked examples, without creating a shadow specification or executing generated
source merely because it was generated.

## Scope

- Execute AX27 against DS2's selected authoring and diagnostic surface.
- Define one versioned machine-consumable projection of composition errors,
  source attribution, canonical artifacts, and supported remedies.
- Ship progressive worked examples from zero-agent local motion through
  portable inspection, durable resume, Activities, and the supported agent path.
- Keep templates, generated packages, examples, documentation, and evaluations
  on public contracts rather than manually duplicated semantics.

## Candidate story seeds

- **TS1 — Machine-readable diagnostics and source attribution.** Expose the
  selected compiler contract without widening runtime authority.
- **US1 — Generate and repair a reviewable flow package.** Produce source and
  diagnostics, require explicit review, and compile only on a separate action.
- **US2 — Progressive worked examples and evaluations.** Teach one coherent
  journey and mechanically detect drift from public contracts.

## Acceptance / Done condition

1. Generated source remains inert until an explicit compile/run action.
2. A generator consumes versioned public diagnostics and canonical artifacts,
   not copied prose or private implementation details.
3. Deliberate invalid output receives deterministic, source-located repair
   guidance and can converge through review to a valid canonical definition.
4. Worked examples cover the same default path and deliberate lower-level
   descent while stating durability and authority honestly.
5. Example and evaluation drift fails mechanically at owned public boundaries.

## Driver QA and evidence plan

- Execute AX27 with valid, invalid, repaired, and malicious/untrusted source
  cases; never execute generated source during generation.
- Compile examples to canonical fixed points and run their documented behavior
  routes under declared profiles.
- Run package/template and documentation coherence checks plus repository gates.

## Out of scope

- A second authoring language or hidden generator runtime.
- Automatic execution, credential injection, or provider authorization.
- Making generated source canonical execution state.
