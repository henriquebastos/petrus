# Product Principles

This directory holds current product behavior principles that guide trade-offs.

Read this index first, then [current principles](current-principles.md). Keep each principle concrete enough to influence product behavior, user experience, implementation choices, or validation.

Keep current truth in the focused principles document. Preserve rationale for consequential changes in `docs/project/decisions/records/` and ordinary textual history in Git. Split principles into domain documents only when distinct domains genuinely change independently.
