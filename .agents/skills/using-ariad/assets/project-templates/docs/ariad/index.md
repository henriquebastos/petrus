Read indexes first and only then focused records. Canonical lifecycle detail belongs in the installed skill; local documents own project truth and deliberate adaptations.

Promote only durable meaning into its smallest project-owned surface, let authorized Git commits preserve ordinary history, and leave conversational residue behind. Fold the receipt into an existing work-closure surface rather than creating a second ceremony.

If the skill cannot be loaded, use this safe kernel: read relevant local context before editing; plan non-trivial work; bound scope; test and give a concrete validation route; update documentation when project truth changes; preserve Process, Project, and Product coherence; stop for Navigator judgment; and follow local commit/push policy.
