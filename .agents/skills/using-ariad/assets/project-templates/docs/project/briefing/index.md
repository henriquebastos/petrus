# Project Briefing

This directory holds concise current context that should not be re-explained in every agent session.

Read this index first, then the focused documents relevant to the work:

- [Identity and purpose](identity-and-purpose.md) — what the project is, whom it serves, its product premises, and shared vocabulary.
- [Current state](current-state.md) — what works now, what is incomplete, and what matters next.
- [Constraints and environment](constraints-and-environment.md) — durable architecture premises, operating environment, boundaries, and hard constraints.

Keep current truth in these documents. Put consequential architectural or product rationale in `docs/project/decisions/records/` and ordinary textual history in Git. Keep commands and development policy in `docs/process/development-guide/` rather than duplicating them here.
