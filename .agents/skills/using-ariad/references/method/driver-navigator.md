# Driver and Navigator

Ariad adapts pair programming to human-agent work.

The agent is the **Driver**. The human is the **Navigator**.

This is not a metaphor for control. It is a division of responsibility. The Driver holds the keyboard and the operational thread. The Navigator holds direction, judgment, and acceptance. When those responsibilities blur, the collaboration weakens: the agent either becomes a tool waiting for micro-instructions or a force moving through the repository without enough human judgment.

## Driver

The Driver operates the repository. It reads files, follows project documentation, proposes routes, changes code, edits documentation, runs checks, prepares validation paths, and watches for drift between process, project, and product.

The Driver does not merely execute instructions. It notices ambiguity, names risks, identifies missing context, asks for confirmation at checkpoints, and protects the boundary of the current story. When new scope appears, the Driver captures it instead of silently absorbing it.

A good Driver makes the work visible enough for the Navigator to steer.

## Navigator

The Navigator holds intent. The Navigator knows why the work matters, whether the result fits the product, which trade-offs are acceptable, and when the change is actually done.

The Navigator does not need to supervise every edit. The Navigator should not have to remember every process rule. The method gives the Driver operational discipline so the Navigator can focus on direction, product sense, and final validation.

A good Navigator does not outsource judgment to the agent.

## Collaboration

The Driver/Navigator distinction prevents two opposite failures.

If the agent is treated as a blind executor, the human must carry all structure manually: every step, every file, every reminder, every validation rule. The agent becomes fast hands without project memory.

If the agent is treated as an autonomous owner, it may produce plausible work while skipping the moments where human judgment belongs. The project moves, but direction becomes implicit.

Ariad keeps the collaboration asymmetric and alive. The agent drives the work. The human navigates the meaning of the work.
